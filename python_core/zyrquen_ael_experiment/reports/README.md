# ZYRQUEN AEL Experiment Reports

This directory stores real JSON and Markdown reports generated by `python3 python_core/zyrquen_ael_experiment/experiment.py`.
Every report records full per-seed comparisons (including ties or losses against Baseline), controller adjustment logs (`before -> after`, `reason_code`, `evidence`), compute budget counters, and fail-closed ApprovalGate records.
