## 5. P11-B Aligned Validation Workflow & Stop Triggers

Every training segment and stage transition MUST follow this closed-loop validation workflow (never declaring PASS without real executed evidence):

```text
[Pre-Flight Audit: SHA-256 + Leakage <= 5% + Random Baseline < 0.05]
        │
        ▼ (Requires Signed Tier-2 Approval)
[Execute Segment (<= 500 steps, CPU<=2, RamMonitor, Dynamic Slots)]
        │
        ├─(NaN / OOM / Disk<2GB / Val Spike >20% / EOS<0.20)──► [ABORT & Rollback to Last Verified Checkpoint]
        │
        ▼ (Segment Complete: Save Atomic ckpt_%08d.pt + SHA-256)
[Track A Check: weights_only=True reload + L2 param delta > 0 + Val Loss Drop]
        │
        ▼
[Track B Native Eval: tools/eval_nagi_v11.py (use_slots=True, permute_slots=False, max_new_tokens=64)]
        │
        ▼ (Compare vs random_init_baseline.json & Prior V11 Checkpoint)
[handle_evaluation_gate() + ModelRegistry (Immutable ZYRQUEN-Native-11.0.x)]
```

### 5.1 Pilot (`500` Steps) Track A & Track B Exit Criteria
- **Track A (Pipeline Integrity — Mandatory PASS):**
  - `parameter_changed == true` (exact L2 weight diff `> 0` vs Step 0).
  - `0` `NaN`/`Inf` events; finite gradient norms after `grad_clip=1.0`.
  - `final_val_loss < step_0_val_loss` with `>= 5%` reduction.
  - `eos_hit_rate >= 0.70` on `validation` at Step `500`.
  - `Peak RSS < 3.0 GiB`, `torch_threads <= 2`, disk delta `< 1.0 GiB`, and `100%` `weights_only=True` + SHA-256 resume test pass.
- **Track B (Capability Reporting — Honest Raw Scores):**
  - Run `tools/eval_nagi_v11.py` across `validation`, `unseen`, `ood` (`max_new_tokens=64`, greedy decode) emitting `zyrquen.v11.evaluation_report.v1`.
  - Report all 6 capabilities separately plus `overfit_gap` (`train_diag - unseen`) against `artifacts/baselines/random_init_baseline.json`. Full NGI certification is **not** expected at Step 500, but scores must never be fabricated or have `unseen`/`ood` omitted.

### 5.2 Stage-6 (`10,000`-Step) Certification Thresholds (`OD-EP-01`)
Promotion candidate evaluation at `Step 10,000` requires passing all independent capability gates simultaneously:
- `eos_hit_rate >= 0.95` across `validation`, `unseen`, and `ood`.
- `knowledge_integration (unseen) >= 0.75` and `abstention_recall >= 0.80`.
- `relational_generalization (unseen) >= 0.70`.
- `multi_step_planning (unseen) >= 0.65`.
- `abstract_reasoning (unseen) >= 0.65` and `ar_inverse_query_acc >= 0.60`.
- `self_verification (unseen)`: `near_miss_rejection_rate >= 0.75` AND `valid_acceptance_rate >= 0.75`.
- `ood_transfer (ood) >= 0.45` (`ood_exact_match > 0.0`).
- `overfit_gap (train_diag - unseen) <= 0.15` and `zero_regression: true` relative to previous registered V11 checkpoints.

### 5.3 Hard Stop & Automatic Rollback Conditions
Training MUST abort immediately (`stop_criteria_triggered` non-empty) and rollback to the last SHA-256 verified checkpoint if any of the following occurs:
1. Any `NaN` or `Inf` in loss or gradients (`math.isfinite` check trips).
2. `validation` loss increases `> 20%` across two consecutive `eval_interval=250` checks, or spikes `> 3.0x` rolling baseline for `>= 50` steps.
3. Single-token repetition collapse exceeds `80%` of greedy generations or `eos_hit_rate < 0.20`.
4. Overfit divergence (`train_exact - unseen_exact > 0.35`) persists across `>= 2` consecutive stages without `unseen` gain.
5. Any `RamMonitor` breach (`>= 3.5 GiB`), disk reserve breach (`< 2.0 GiB` free), SHA-256 mismatch, or leakage gate failure (`EL/TL/SL/DL`, `> 5%` n-gram overlap).
